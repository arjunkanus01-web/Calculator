erra Calculator

A calculator project made with Python!

 Terra Calculator?

Hey! This is Terra Calculator, a project I've been working on using Python and PySide6.

I wanted to make my own calculator instead of just using the normal one on my computer. I also wanted it to look really good, so I went with a clean pearl-white design inspired by Apple's liquid glass style.It looks really good btw.

But it's not just about looks. I've added scientific functions, keyboard controls, animations and even started building a desktop environment around it!



 Calculator features

Addition, subtraction, multiplication and division

Square root (√)

Square (x²)

Powers (xʸ)

Reciprocal (1/x)

Logarithms (log and ln)

Percentage

Positive/negative number conversion

Pearl-white theme

Desktop interface

 What did I use?

Python – to write the actual program.

PySide6 – to build the interface.

Qt – for the buttons, layouts and animations.

Math module – for scientific calculations.

 How to run it

First, install PySide6:

pip install PySide6

Then run:

python "Terra Calculator.py"
